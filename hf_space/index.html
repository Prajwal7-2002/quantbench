Transformer Layer Sensitivity Analysis
Layer-by-layer Signal-to-Quantization-Noise Ratio (SQNR) retention & Outlier Resilience
Scheme:

💡 Architectural Insights

  • Attention Q & K Projections: Most vulnerable to quantization. Phase drift in query/key dot-products leads to exponential attention softmax dispersion.
  • MLP Gate & Up Projections: Most resilient. Non-linear activations (SwiGLU/GeLU) naturally dampen small magnitude quantization errors.
  • MLP Down Projection: Acts as an information bottleneck compressing representations back into d_model, requiring higher precision or finer group sizes.
Mixed Precision Strategy:
Keep Q, K, and Down-proj in INT8 or INT4 AWQ (G=32), while compressing Gate, Up, and Value into aggressive 2-bit or INT4 (G=128) to achieve optimal throughput with 0 PPL degradation.

Sub-Byte Bit-Packing Python Example:
import torch from quantbench.quant.packing.ternary_pack import pack_ternary, unpack_ternary from quantbench.quant.packing.int4_pack import pack_nibbles, unpack_nibbles from quantbench.quant.packing.sparse_pack import prune_and_compress_2_4 # 1. BitNet 1.58b Ternary Packing (7.5x compression) weights = torch.tensor([-1, 0, 1, -1, 0, 1, 1, -1], dtype=torch.int8) packed_bytes, orig_len = pack_ternary(weights, mode="2bit") unpacked = unpack_ternary(packed_bytes, original_length=orig_len, mode="2bit") assert torch.equal(weights, unpacked) # 2. INT4 Nibble Packing byte_val = pack_nibbles(low=-3, high=5) low, high = unpack_nibbles(byte_val, signed=True) print(f"Packed byte: 0x{byte_val:02X}, Unpacked: [{low}, {high}]") # 3. Ampere 2:4 Structured Sparsity dense_block = torch.tensor([[0.45, -0.12, 0.88, 0.05]]) compressed, indices = prune_and_compress_2_4(dense_block) print(f"Retained non-zeros: {compressed}")
