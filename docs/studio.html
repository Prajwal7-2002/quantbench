Transformer Layer Sensitivity Analysis
One projection type quantized at a time (all 24 layers), everything else in BF16. Bar length = measured perplexity change, scaled to the worst layer for this scheme (at least 2%).

💡 What the measurement shows

  • INT8 per-channel: quantizing any single projection type changed perplexity by at most 0.15%.
  • INT4 G=128: MLP Down (down_proj) hurt most (+8.25%), Attention Query (q_proj) least (+0.81%). Weight SQNR was nearly identical across layer types, so SQNR alone does not predict which layers matter.
  • 2:4 sparsity and post-hoc ternary: large perplexity increases even when applied to one projection type (up to 2,594,285%).
Impact bands: Low < 2%, Moderate < 10%, High ≥ 10% perplexity change. One model and one evaluation text; effects do not simply add up when several layer types are quantized together.

Sub-Byte Bit-Packing Python Example:
import torch from quantbench.quant.packing.ternary_pack import pack_ternary, unpack_ternary from quantbench.quant.packing.int4_pack import pack_nibbles, unpack_nibbles from quantbench.quant.packing.sparse_pack import prune_and_compress_2_4 # 1. Ternary packing: 4 values per byte (8x smaller than BF16 before the scale) weights = torch.tensor([-1, 0, 1, -1, 0, 1, 1, -1], dtype=torch.int8) packed_bytes, orig_len = pack_ternary(weights, mode="2bit") unpacked = unpack_ternary(packed_bytes, original_len=orig_len, mode="2bit") assert torch.equal(weights, unpacked) # 2. INT4 Nibble Packing byte_val = pack_nibbles(low=-3, high=5) low, high = unpack_nibbles(byte_val, signed=True) print(f"Packed byte: 0x{byte_val:02X}, Unpacked: [{low}, {high}]") # 3. Ampere 2:4 Structured Sparsity dense_block = torch.tensor([[0.45, -0.12, 0.88, 0.05, 0.31, 0.02, -0.77, 0.10]]) compressed, metadata = prune_and_compress_2_4(dense_block) print(f"Retained non-zeros: {compressed}")
